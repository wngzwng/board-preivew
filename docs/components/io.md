# 导入导出组件

负责 **文件选择、读取、校验、写入**，以及导出内容的**打包策略**（按标签 / 全部、是否附带操作历史）。不实现具体编解码算法，**依赖编解码组件**提供的字符串与结构化数据互转。

## 职责边界

| 属于本组件 | 不属于本组件 |
|------------|----------------|
| `FileReader` / `input[type=file]`、`Blob`、下载触发 | `level_str` 的解析与拼接规则 |
| 文本编码（建议统一 **UTF-8**） | 单个预览框内的旋转/镜像绘制 |
| 导出 JSON / **CSV** / 文本的结构设计、版本字段 | CSS Grid 布局样式 |

## 导入流程

1. **选择文件**：接受用户选取的一个或多个文件（若产品允许多文件）。  
2. **读取为文本**：`readAsText`（或等价 API），编码 UTF-8；失败时提示「无法读取文件或编码不符」。  
3. **格式识别**（按产品约定扩展）：  
   - **纯关卡串**：整文件即一个 `level_str`，对应一个预览槽位或一个条目。  
   - **JSON 包**：解析根对象，读取版本号、关卡列表等；未知版本时**拒绝导入**并提示升级工具。  
   - **CSV**：选择 UTF-8 文件后**解析首行**；若勾选「首行作为表头」，以下拉框展示各列表头，用户选择关卡串所在列，**默认选中名为 `Content` 的列**（不区分大小写）；未勾选则列为「列 0」「列 1」…，默认第 0 列。实现见 `src/io/csv.js` 与 `board-preview-app`。  
4. **校验**：  
   - 空文件、超大文件（超过上限）直接拒绝。  
   - 调用编解码尝试解码；失败时返回行号/片段（若可得）而不崩溃。  
5. **交给 UI**：将合法结果分发给网格中的预览实例（事件或 store）。

### 导出 CSV（与 JSON 并列）

- **保留原始 CSV 的列**：导入 CSV 时记录每行原始单元格；导出时按相同顺序原样回写。  
  - 没有原始 CSV 的预览框（如手动新增）原始列以空字符串占位。  
  - 无原始表头时，原始列在表头行用 `列 0`、`列 1`… 占位。  
- **追加 4 个新列（顺序固定）**：  
  - `sourceLevel`：导入或上一次「解码 / 应用」时的源关卡串。  
  - `operator`：操作字符串（按 [Board 操作集](board-operations.md) 字符表，如 `LXZ`）。  
  - `targetLevel`：当前关卡串。  
  - `HasZOperator`：本次是否触发过 Z 轴反转，`1` / `0`。  
- **可选「Index」列**：勾选「添加 Index 列（1 起自增）」时，在最前追加一列 `Index`，按导出顺序从 1 开始自增；起点可由代码侧 `indexStart` 覆盖。
- 含逗号/换行时按 RFC4180 用引号转义；文件带 **UTF-8 BOM**，便于 Excel 打开不乱码。

### 标签输入

- 页头提供「**预设标签**」输入框，使用逗号 / 中文逗号 / 空白分隔多项；自动去重并广播给所有预览框。  
- 单个预览框不再使用文本输入，改为：**已选 chip 列表 + 「+ 添加」下拉**。下拉中含两类项：
  - 预设标签（点击即作为 chip 加入）。  
  - `自定义…`：弹出输入框，可一次输入多个（逗号分隔）。  
- chip 上的 `×` 按钮即时移除标签，导出时与之前一致以 `tags` 数组写出。

## 导出流程

### 导出粒度

- **全部导出**：当前工作区内所有预览框的最终 `level_str`（或结构化数据经编码后的结果）。  
- **按标签导出**：仅导出带指定标签的预览框；无标签过滤命中时给出明确提示（非静默空文件）。

### 建议的导出载荷（JSON 示例形状，字段名可调整）

为支持「源 board、操作、新 board、Z 轴是否参与」等需求，推荐每个预览条目至少包含：

几何变换的 `type` 与语义见 [Board 操作集](board-operations.md)（`rotate_left`、`rotate_right`、`mirror_x`、`mirror_y`、`flip_z`）；标签类操作可用 `tag_*` 等于该页约定。

```json
{
  "version": 1,
  "items": [
    {
      "id": "可选的稳定 id",
      "tags": ["默认或自定义"],
      "sourceLevelStr": "编辑前的关卡串",
      "operations": [
        { "type": "rotate_left", "payload": {} },
        { "type": "mirror_y", "payload": {} },
        { "type": "flip_z", "payload": {} }
      ],
      "levelStr": "当前关卡串",
      "meta": {
        "hadZAxisOperation": true
      }
    }
  ]
}
```

- **`operations`**：若产品简化，可仅存最终串，但会丢失复盘能力；与 README 中「有操作则记录」一致时建议保留。  
- **`hadZAxisOperation`**：由预览交互层在发生 Z 轴相关变换时置为 `true`。  
- **纯文本导出**：可仅写 `levelStr` 列表或换行分隔的多关，需在 UI 上标明格式，避免用户误以为 JSON。

## 文件扩展名与 MIME

- 由产品约定（如 `.json` + `application/json`，或 `.txt` + `text/plain`）。  
- 下载时使用 `Blob` + 临时 `<a download>` 或 **File System Access API**（若需覆盖写盘，注意浏览器兼容与权限）。

## 错误处理

- **读取失败**：网络/权限/编码 → 用户可读中文说明。  
- **JSON 解析失败**：提示「文件不是合法 JSON」；不尝试用关卡解码器去解整个文件。  
- **解码失败**：透传编解码组件的错误信息。  
- **写入/下载被拦截**：提示检查浏览器下载设置或弹窗策略。

## 与其它组件的契约

- 只通过 **编解码组件** 生成/消费 `level_str`。  
- **渲染组件** 在每次有效编辑后推送最新 `levelStr` 与操作增量，供导出聚合。
