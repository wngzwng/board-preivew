# 编解码组件

将 **Board / 关卡字符串**（`level_str`）与内存中的**结构化牌位列表**互转。本项目关卡为 **Tile3 叠层棋盘**（羊了个羊类），**层 `z`** 与 XY 共同决定牌位；解码后的列表不含贴图信息，**花色 / 类型与 `src/assets/` 资源的对应**在渲染层完成。前端建议实现为**纯函数模块**或 **Web Component 的私有工具层**，不直接操作 DOM。

## 参考实现

- 逻辑以仓库根目录 **[`format.py`](../../format.py)** 为准。
- `format.py` 依赖工程内的 `mahjong.constants.MahjongSplitChar` 与 `.common` 中的 `char_to_number` / `number_to_char`。移植到浏览器时，需将**分隔符常量**与**数字↔单字符编码**规则一并固化到同一模块，避免与后端/工具链不一致。  
  - **编码规则**（与 Python 一致）：`0`–`9` → 0–9，`A`–`Z` → 10–35，`a`–`z` → 36–61；见 `src/codec/charMap.js`。

## 核心数据模型

与 `RawPositionWithSuitData` 对齐的语义（字段名可按语言习惯映射，含义保持一致）：

| 字段 | 含义 | 备注 |
|------|------|------|
| `x` | 行 | 与解析时的「行」片段对应 |
| `y` | 列 | 与解析时的「列」片段对应 |
| `z` | 层 | 与解析时的「层」片段对应 |
| `suit` | 花色 | 可为空字符串；有花色时与坐标列表按顺序一一对应 |

排序约定（与 `RawPositionWithSuitData.sort` 一致）：按 `(z, x, y)` 升序排列，便于与格式化器的状态机假设一致。

## 关卡字符串结构（解码入口）

1. 使用 `POSIT_SUIT_SPLIT_CHAR` 分割：当前 Python 实现为 `level_str.split(...)`（**全局分割**）。若分隔符在花色区也可能出现，需与业务约定一致；前端移植时建议显式采用「只分割成位置段 + 剩余为花色段」的策略（等价于 `split(sep, 1)`）以避免二义性。
2. 第一段为 **位置数据** `position_data`，第二段为 **花色数据** `suit_data`（可选）。
3. **解码**（`from_level_str`）：  
   - 对 `position_data` 按「层 → 行 → 列」分隔符逐级 `split`，每层取首字符为层号，其余再分行；每行首字符为行号，其余再分列；每列片段经 `char_to_number` 得到列号。  
   - 若存在 `suit_data`，将迭代得到的每个 `(x,y,z)` 与 `suit_data` 中**逐个字符**（当前实现为按字符 zip）组合为带花色的记录；否则花色为空。

## 编码（序列化）

1. **位置串**：由 `PositionDataFormatter.format` 根据列表顺序输出；遍历每条记录时依次处理 `z`（layer）、`x`（row）、`y`（column）。  
2. **分隔规则**：  
   - 同一维度上坐标**与上一条相同**则该维度不再输出（省略重复）。  
   - 坐标**变化**时：若非该维度首次写入，先追加该维度的分隔符，再写入 `number_to_char(value)`。  
   - **层**变化时重置行、列的内部状态；**行**变化时重置列状态。  
3. **重复校验**：若在同一维度上出现「曾经出现过的坐标值再次出现且与当前 last 不同」等重复场景，Python 实现会抛出 `ValueError`（如 `{coord_type}重复: {value}`）。前端应对等抛出或返回 `Result` / 拒绝编码，并向上层展示可读错误。  
4. **整串输出**（`to_level_str`）：  
   - 若列表中任一元素有非空 `suit`，则在位置串后追加 `POSIT_SUIT_SPLIT_CHAR` 与所有 `suit` 按顺序拼接；  
   - 否则仅返回位置串。

## 公开能力清单（对照 `format.py`）

| 能力 | Python 符号 | 说明 |
|------|-------------|------|
| 遍历位置 | `iter_pos_from_position_data` | 仅输入位置段字符串 |
| 遍历花色 | `iter_suit_from_suit_data` | 按字符迭代花色串 |
| 解码 | `from_level_str` | `level_str` → 列表 |
| 编码 | `to_level_str` | 列表 → `level_str` |
| 排序 | `sort` | `(z,x,y)` 排序 |
| 仅编位置 | `PositionDataFormatter.format` | 列表 → 位置段 |
| 仅取花色串 | `SuitDataFormatter.format` | 列表 → 花色段或空 |

## 与其它组件的契约

- **导入导出**：只传递 UTF-8 文本层面的 `level_str` 或 JSON 中的字符串字段；不在此层做文件 IO。  
- **渲染**：接收解码后的列表（或渲染专用投影）；编辑后通过编码回写字符串。  
- **操作记录**：记录的是「对结构化数据或视图的变换」，导出前需能重放到列表再编码，或记录最终 `level_str`（见 [导入导出组件](io.md)）。

## 错误处理建议

- **非法字符**、**无法解析的片段**：返回明确错误类型（如 `DecodeError`），附带原始片段索引或截断预览。  
- **坐标与花色数量不一致**：解码阶段即失败，避免静默错位。  
- **编码阶段重复坐标**：与 `format.py` 对齐抛错，不在 UI 层吞掉。
