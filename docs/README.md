# Board 预览

面向 **Tile3 类叠层关卡**（与「羊了个羊」同类：**多层牌块叠放**、依赖 `z` 层序与露出区域）的 Board 预览与编辑说明；页面整体采用**前端网格布局**组织多个预览区域。

## 产品与资源

- **关卡形态**：Tile3 board；坐标与编码用 [编解码](components/codec.md) 约定的 `(row, col, z)`（对应 `format.py` 的 `(x, y, z)`），**层 `z` 对叠放与遮挡关系尤为关键**。  
- **棋子美术**：使用 **`src/assets/`** 下的贴图等资源，**由渲染实现自行引用**（不打包进编解码逻辑）。当前示例文件包括牌底、牌面等（如 `tilebase_*.png`、`tilebase_card_*.png`）；后续新增素材直接放入 `src/assets/` 即可在文档外扩展，路径常量见 `src/assets/tileSources.js` 中的 `ASSETS_BASE`。

## 功能概览

### 文件

- 支持关卡 / Board 相关文件的**导入**与**导出**。

### 页面布局（前端网格）

- 使用 **CSS Grid 等前端网格布局** 在页面上栅格排列多个预览框。  
- 这里的「网格」指**界面排版**（多列/多行的预览容器），与单个关卡 / Board 内部的棋盘格子不是同一概念。

### 每个预览框支持的操作

1. **左右旋转**
2. **X、Y 镜像**
3. **Z 轴反转**
4. **标签标记**：内置默认标记；支持外部输入**自定义标签**。

### 导出策略

- 可按**标签**筛选导出。
- 支持**全部导出**。

### 操作记录与导出元数据

存在编辑操作时，会**记录操作历史**。后续导出时除结果数据外，还可包含例如：

- **源** board 字符串  
- **操作**序列  
- **新** board 字符串  
- 是否发生过 **Z 轴**相关操作  

便于复盘、自动化处理或与外部工具对接。

## 模块划分

| 序号 | 模块 | 说明 |
|------|------|------|
| 1 | 解码与编码 | Board / 关卡字符串与内部数据结构的互转（实现时可对照 `format.py`） |
| 2 | 导入与导出 | 文件读写与格式处理 |
| 3 | 关卡渲染 | 在界面中绘制与交互 |

### 编码与解码（实现参考）

- 仓库根目录的 **`format.py`** 可作为**编码、解码逻辑**的对照实现：其中包含三维坐标（层 / 行 / 列）的解析与序列化、分隔符使用、以及位置与花色数据的组合方式（如 `RawPositionWithSuitData`、`PositionDataFormatter` 等）。
- 在前端用 JavaScript 重写时，建议**保持与 `format.py` 相同的拆分与拼接规则**，以便与现有关卡字符串及工具链互通。若 `format.py` 依赖项目内的分隔符常量等定义，移植时需一并核对对应规则。
